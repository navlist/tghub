# 怎么添加好友

添加电报好友分三种情况：

## 1.电报内搜索加好友

使用这种方式添加好友，需要知道对方的电报号，类似于微信号一样，但是要以@开头，例如直接在电报搜索框输入@wanzhuandianbao 就能搜索到对方账号

## 2.添加群好友

添加群好友就比较简单，点击该用户的头像，然后进入用户的个人信息页面，就能找到添加为联系人的按钮

## 3.扫码加好友

在个人资料里，可以跟微信一样把自己的电报号通过二维码分享出去。但这里重点区别就是，扫码的一方，不是打开电报去扫（没有扫一扫添加的功能），需要使用手机自带的摄像头或者浏览器扫码跳转打开。
以下是详细的步骤：

- 打开你的 Telegram 应用并确保你已经成功登录
- 使用手机自带摄像头或者任意扫码软件（微信、知乎、百度等等扫码软件都可以）扫描好友的二维码
- 扫码成功打开链接，在链接里面你会看到一个按钮叫做 send message，直接点击 send message，就会拉起会话
  进入聊天界面，这样就可以进行聊天，点击右上角好友头像进入好友主页
- 在个人资料页面上，可以看到点击添加为联系人选项，点击添加联系人并备注，这样就将好友添加到你的联系人列表中了

## 小窍门

Telegram 电报生成的二维码上都有@xxxx，不方便扫码的话，我们也可以直接在电报里搜索@后面的那串字符（即方法 1），就可以搜索到对应的用户、群组和频道

## ⚠️ 添加好友隐私问题

请特别注意，在添加好友的时候，默认会共享手机号，在新建联系人页面有一个选项叫做分享我的手机号，这里一定要关闭，如果不关闭就会导致你的手机号被泄漏了。
