# 如何查看复制群组频道链接

> 查看与复制频道链接最快的方法

需要注意的是，群组跟频道分为【公开】和【私密】，如果管理员设置为私密的话，成员无法直接看到链接，下面方法针对公开频道。

# 查看复制群组频道链接

## 方法一：点击顶部【频道名称】查看资料

不要点右上角的三个点；
直接鼠标点击顶部正中央的名字；
界面右侧会滑出频道详情页（Channel Info）；
页面中会直接显示该频道的公开链接（格式类似 t.me/xxxx），点击链接旁边的复制图标即可分享。


## 方法二：右键任意一条消息【复制链接】

在右侧聊天区域中，找到任意一条消息；
鼠标右键点击该消息；
在弹出的右键菜单中选择 「Copy Link」（复制消息链接）；
复制出来的链接格式形如 https://t.me/xxxx/411：
这样分享给别人，对方点开不仅能直接看到该内容，还可以直接点击进入并关注该频道；
如果只想分享频道主页，将链接末尾的消息数字（如 /411）删掉即可。
