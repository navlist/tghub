# 电报 telegram 收不到验证码解决方案

首先，电报是支持中国手机号注册登录的，如果你在注册过程中收不到验证码，请按下面问题排查步骤进行。

## 问题排查

### 确认有梯子翻墙软件

Telegram 在国内是屏蔽的，要想正常使用，没有梯子或者翻墙软件是肯定没办法使用的，所以要首先排除这个问题。如果你还没有靠谱的梯子翻墙软件，这里[点击查看 VPN 飞机 ✈️ 推荐](../../../docs/money/vpn.md)

### 手机是否有 sim 卡

手机如果没有卡，telegram 是不会发送短信的，只会发送设备码，因此要先确认下是不是有 sim 卡，否则就无法收到短信了。

### 官网最新版本

telegram 目前只有官网下载的版本才会发送短信，其他的第三方下载的版本都只会发送设备码，如果你不知道当前安装的是不是官网下载的，建议重新去官网下载一个最新版本[点击打开官网地址](https://telegram.org)，如果是苹果手机则直接去苹果应用商店下载更新。

### 设备码 device code 和 sms code 区分

类似于苹果登录多设备，有时会直接发送验证码到你已经登录过的设备上弹窗显示，电报也会将验证码发送到你已经登录的设备上，如果提示的是 device code，就需要你查下已经登录过电报号的设备上查看下消息。sms code 则是直接短信的方式接收。
